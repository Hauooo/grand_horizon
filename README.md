# GA_Horizon

GA_Horizon is a Grand Archive season companion for tracking store championships, local weekly events, and broader regional tournament activity.

## Project purpose

This project is designed to help players and organizers keep tabs on:

- weekly event calendars
- store championships
- regional event listings
- venue detail pages with navigation links
- season data that can be extended into standings and qualification tracking

## Included in this repo

- `index.html` — the main season/event index page
- `PRD Shore Champs Malaysia.csv` — source event data for the PRD season
- `The Weatherlight Enterprise/` — store-specific event detail page and assets

## Local usage

Open `index.html` in a browser to view the current event list.

If you want to open a specific store detail page, use the event card link or open the folder in the browser directly.

## Notes

This project is currently structured as a lightweight static front-end and is intended to be expanded into a fuller season management app.
